**Crema 1.4.0**

The update that reaches the external monitor.

**Highlights**

- **External display brightness, both ways, via BetterDisplay.** With
  BetterDisplay's OSD notification on, the brightness bar for a managed monitor
  is drawn by Crema — on that monitor, in your chosen style — and dragging it
  writes back through BetterDisplay's own channel, on the same scale it
  reported. No BetterDisplay? Nothing changes; the integration is inert.
- **The brightness key follows the pointer.** Crema adjusts the built-in
  display while the pointer is on it; aimed at any other display, the key is
  handed back whole to whoever can move that screen. No more dimming the
  laptop while looking at the monitor.
- **An indicator that appears where it belongs.** A HUD that names a display
  shows only on that display. Volume and keyboard backlight, which no screen
  owns, stay everywhere.
- **An honest bar.** A drag that no actuator honoured springs back to the last
  level that was really applied — at the end of the gesture, never under your
  finger. A control that did nothing no longer looks like one that worked.
- **A menu that leads with the switch.** Replacing the system indicators is now
  one click from the menu bar, and every warning carries its fix right below —
  including a button that opens Settings on the tab that solves it.
- **Settings, redrawn.** Pick a style by looking at it: thumbnails derived from
  each style's real layout, on a screen with a menu bar and a Dock-free desk.
  The System HUD tab is now Indicators, permissions read as Required and
  Optional, and every label says what it does.

**Reliability**

A fast drag on the external monitor's bar no longer flicks backwards; a
keyboard backlight that enumerates late is picked up on the next press instead
of staying dead for the session; a stalled system read can no longer freeze the
app — every availability check now races the same deadline as the writes; and
the media-key tap survives display topology changes without going deaf.

Updating from 1.2.0 happens in place via Sparkle. First install? Drag Crema to
Applications and use "Open Anyway" on first launch — the build is self-signed.
